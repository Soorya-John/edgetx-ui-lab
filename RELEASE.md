# v0.1.0-alpha.1

The first EdgeUI alpha is an installable EdgeTX Tools preview for the RadioMaster Pocket. It introduces a four-page navigation layout, active model summary, receiver link indicator and radio information page. Navigation uses the radio's existing roller and virtual key events.

Lua 5.2 smoke checks exercise page navigation, back and exit behavior, missing model information and absent RSSI. Physical Pocket operation and visual fit still need validation. The alpha reads radio information and does not write settings or model data.

Install the `EdgeUI.lua` asset under `SCRIPTS/TOOLS` on an EdgeTX SD card. See the README for the launch path.
