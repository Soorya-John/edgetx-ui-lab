# Interface direction

The Pocket screen has 128 × 64 pixels, so each page has one clear title, one primary fact and a consistent back action. The page list is the entry point. The top bar identifies the current page, and the bottom row shows the available action.

The alpha explores a hierarchy for four common questions. Home answers which model is active. Model gives that name room to breathe. Telemetry shows whether a receiver link is visible. Radio identifies the firmware and transmitter target. The concept uses EdgeTX's monochrome drawing primitives and physical navigation events.

Future design work can replace the preview's simple text with measured layouts, then evaluate them on each target radio and in Companion. Any controls that modify model or radio state require explicit interaction design and validation before implementation.
